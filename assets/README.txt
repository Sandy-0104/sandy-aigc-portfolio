作品素材放置说明
================

把桌面上的素材文件放到当前这个 assets 文件夹中，并按下方表格命名。
命名必须完全一致（包括大小写和扩展名），网页才能正确加载。

------------------------------------------------------------------------
新增的 3 个作品需要的文件：
------------------------------------------------------------------------

【1】汽车广告短片（视频作品）
  - 视频文件：   car-ad.mp4
  - 封面截图：   car-ad-poster.jpg   （可用视频任意一帧截图作为封面）

【2】千墩冬工坊 · 角色（图片作品）
  - 角色图片：   qiandun-character.jpg

【3】千墩冬工坊 · 成片（视频作品）
  - 视频文件：   qiandun-final.mp4
  - 封面截图：   qiandun-final-poster.jpg

------------------------------------------------------------------------
操作步骤：
1. 打开本机文件管理器，进入本网页所在目录的 assets 文件夹。
2. 把桌面上对应的素材文件复制/重命名为上表中的文件名。
3. 刷新 portfolio.html 即可看到作品。
4. 若文件名不同，可打开 portfolio.html，在 WORKS 数组里修改对应
   thumbnail / videoSrc 路径。
